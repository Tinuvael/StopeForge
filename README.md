# StopeForge

Open-source desktop application for empirical open stope design.

![GitHub Release](https://img.shields.io/github/v/release/Tinuvael/StopeForge)
![License](https://img.shields.io/github/license/Tinuvael/StopeForge)

## Download

Download the latest release from the **Releases** page.

➡ https://github.com/Tinuvael/StopeForge/releases/latest

## Features

- Open stope stability assessment using the Mathews–Potvin stability graph
- Case history database for mined stopes
- Interactive visualization of case histories on stability graphs
- Creation and editing of custom stability boundaries
- Project management
- PDF report generation

## Disclaimer

StopeForge is an engineering support tool implementing published empirical methods.

The software does not replace professional engineering judgement. Users are responsible for verifying all calculations and design decisions.
